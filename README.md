# Option Pricing
A C++ based option pricing project that implements different mathematical and computational models for pricing financial options.

The project is being developed as a web application where users can select an option pricing model, enter the required parameters, and get the calculated result.

## Models
### Black Scholes
The Black–Scholes model is used to calculate the theoretical price of European style options. It is based on geometric Brownian motion with constant volatility and a constant risk-free interest rate.
#### Implemented Features
* Call & Put Pricing.

#### Future Planned Features
* Greeks
  * Delta
  * Gamma
  * Theta
  * Vega
  * Rho
* Implied Volatility
* Dividend Yield
* Call-Put Parity
* Payoff & Profit Analysis
* Sensitivity Analysis
### Monte Carlo 
A Monte Carlo simulation in finance is a computerized mathematical technique that predicts the probability of various financial outcomes by running thousands of random what-if scenarios.
#### Future Planned Features
* Monte Carlo Option Pricing.
### Binomial Tree
A binomial tree in finance is a graphical, step-by-step model used to predict the future price paths of an underlying asset and calculate the fair value of options or other derivatives.
#### Future Planned Features
* European Option Pricing
* American Option Pricing
* Convergence Analysis
### Trinomial Tree
A trinomial tree is a lattice-based financial model used to price options and interest rate derivatives by mapping three possible asset price paths—up, down, or stable—at each time step.
#### Future Planned Features
* European Option Pricing
* American Option Pricing
* Convergence Analysis

## Web Application
A web application is planned for the project.

As additional models and features are implemented, they will be integrated into the web application.
